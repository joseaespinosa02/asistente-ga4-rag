# Documentos propios (opcional)

La base de conocimiento descarga automáticamente la documentación oficial de GA4 listada en `src/config.py`.

Si quieres ampliarla, deja aquí archivos **PDF, .md o .txt** (por ejemplo, tus apuntes del curso de certificación de GA4) y vuelve a ejecutar la sección de indexación del notebook. Se indexan junto con el resto.

> Sube a GitHub solo documentos que sean tuyos o de licencia libre.
